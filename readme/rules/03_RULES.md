## لماذا هذه القائمة موجودة أصلاً

قاعدة القالب الحاكمة: **ما يفشل بصمت أخطر مما ينهار.** انهيارٌ يُبلّغ عن نفسه
ويُصلَح بيومه؛ أما مفتاح JSON خاطئ أو موديول مطفأ أو وثيقة متقادمة فتبقى **شهوراً**
بينما `dart analyze` نظيف والاختبارات خضراء. كل قاعدة أدناه تحوّل عطلاً صامتاً إلى
عطلٍ ينطق.

| الرمز | المعنى |
|---|---|
| 🔒 | **يفرضها فاحص آلي** — تكسر البناء أو الاختبار |
| 👁 | **مراجعة بشرية فقط** — لا شيء يمسكها غيرك |

## أ) عقد الـwire — الأخطر على الإطلاق

### R01 · مفاتيح JSON عقدٌ مع الباك 🔒

كل مفتاح تقرؤه من الاستجابة **عقدٌ** مع `backend_template`، لا تفصيل داخلي.

**عند تغيير أي مفتاح — الثلاثة بنفس التغيير:**

```
1. lib/features/<f>/data/models/<x>_model.dart
2. test/fixtures/wire/<x>.json
3. backend_template/src/features/<f>/__tests__/wire-contract.test.ts
```

> **لماذا**: نموذجٌ يقرأ `data.user` والباك يرسل `data.account` يُسقط الدخول كلّه —
> والسيرفر يسجّل `200 OK` ويُنشئ جلسة حقيقية.
>
> **ولا يراه شيء**: `dart analyze` نظيف (مفتاح غائب = `null` = `dynamic` سليم) ·
> `tsc` نظيف (الباك لا يعلم بوجود عميل) · `HandleBodyResponse` يبتلع الاستثناء
> فيصبح `Failure` عامّة بلا stack · CI أخضر بالطرفين.

**والحارسُ الآليّ قائمٌ بالقالب**: `test/wire_contract_test.dart` يفكّ كلَّ ملفٍّ
بـ`test/fixtures/wire/` بنماذجه الحقيقية ويؤكّد المفاتيح — فمفتاحٌ يتبدّل يُسقط
اختباراً أحمر بدل أن يمرّ `null` صامتاً.

⚠️ **وهو يحرس ما بالجرد وحده.** شريحةٌ تُضاف بلا ملفِّ تثبيتٍ وبلا صفٍّ بذلك
الاختبار **تبقى بلا حارس**، والقاعدة تُقرأ عندها انضباطاً لا فحصاً.

**والمرجع القاطع للعقد `GET /openapi.json`** — لا مجموعة Postman ولا وثيقةٌ
نثرية: تلك لقطاتٌ مصدَّرة تحمل قيماً وهمية تُخفي اختلافَ قواميس الخيارات.

> 📌 **ومشروعٌ يريد فاحصاً يسأل الخادمَ الحيَّ** — لا ملفَّ تثبيتٍ ساكناً — يبني
> سكربتاً يقارن جردَ حقوله مقابل `openapi.json` ويفشل بصوتٍ عالٍ. والنمطُ كاملاً
> ورموزُ خروجه الثلاثة: [`40_SCRIPTS.md`](../scripts/40_SCRIPTS.md) §8‑ب.
>
> **والفرق بينه وبين ملفّ التثبيت جوهريّ**: هذا يقول «النموذجُ ما زال يقرأ ما
> اتّفقنا عليه»، وذاك يقول **«والاتفاقُ ما زال قائماً»** — والثاني وحده يمسك
> حقلاً بدّله الباك بصمت.

### R02 · الرفض يُميَّز بحقل بنيوي لا بنصّ الرسالة 👁

```dart
// ✅  ApiError.data['account_status']
// ❌  message.contains('غير مفعّل')
```

> **لماذا**: نصّ الرسالة نثرٌ مترجَم يتغيّر بالصياغة — **وبلغة كل طلب**
> (`Accept-Language`). مطابقة النصّ تنكسر بلا أن يلمس أحد الكود.

### R03 · كلمة مرور حالية خاطئة = 422 لا 401 🔒

> **لماذا**: الطلب موثَّق، فـ401 تعني «الجلسة باطلة» ويردّ عليها المعالج المركزي
> **بتسجيل خروج**. خطأٌ بحقل واحد يطرد المستخدم من التطبيق — يُقرأ انهياراً لا
> تصحيحاً. الفاحص: `refusal-shapes.test.ts` بالباك.

## ب) الحالة والدورة

### R04 · `SafeCubit` لا `Cubit` — بلا استثناء 🔒

```dart
class XCubit extends SafeCubit<XState> { }   // ✅
class XCubit extends Cubit<XState> { }       // ❌
```

> **لماذا**: كل جلب يتجاوز شاشته عاجلاً أو آجلاً — رجوع، إغلاق ورقة، أو
> `ListView` يتخلّص من قسم. فيصل الردّ إلى cubit مغلق و`emit` يرمي
> `Bad state: Cannot emit new states after calling close` — **انهيار حقيقي يصل نسخة
> الإصدار**، سببه لا أكثر من مغادرة شاشة بسرعة.
>
> **ولا تكتب `close() { _useCase.cancel(); }` ظنّاً أنها الحماية** — الدالة غير
> موجودة، ولو وُجدت لما كفت: الردّ قد يصل بين «تحليل الاستجابة»
> و«إغلاق الـcubit». من احتاج إلغاءً فعلياً يمرّر `CancelToken` الخاص بـDio.

الفاحص: `test/safe_cubit_test.dart`.

### R05 · كلُّ state صنفٌ `sealed` — و`@freezed` بـ`features/` 👁

الشمولية هي الغرض: حالةٌ تُضاف لاحقاً تصبح **خطأ ترجمة** بكل مستهلك، لا فرعاً
منسيّاً بصمت. و`sealed` يعطيها وحده؛ `@freezed` يزيد `copyWith` والمساواة.

| أين | الشكل | لماذا |
|---|---|---|
| `lib/features/` | `@freezed` — إلزامي | شرائح المشروع، و`gen_code` يعمل عليها أصلاً |
| `lib/modules/` · `lib/ui/state/sync/` | `sealed` مكتوبٌ باليد، وفوقه سطرٌ يقول ذلك | الموديول يُشحن مطفأً، فلا يُلزم مشروعاً لا يُشعله بملفات توليد |
| `RefreshState` | صنفٌ عاديّ **بلا مساواة** | كل `emit(RefreshState())` يجب أن يُعاد البناء به؛ `@freezed` يجعل النسختين متساويتين فيُسقطه الـcubit |

### R06 · `context.mounted` بعد كل `await` 👁

```dart
await _service.call();
if (!context.mounted) return;      // ← إلزامي
context.router.push(...);
```

### R07 · الـCubit يعتمد على UseCase لا Repository 👁

ولا يعرف الـRouter إطلاقاً — يبعث `AuthEventBus` ويترك التنقّل لـ`app.dart`.

### R08 · كل مسار يُسجَّل بـ`router.dart` **ويُضاف لاختبار العقد** 🔒

```
1. @RoutePage()
2. router.dart      → AutoRoute(...)
3. router_contract_test.dart → 'XRoute'
```

> **لماذا**: `auto_route` يولّد `PageRouteInfo` لكل

>
> `dart analyze` لا يراه. ولا اختبار widget للشاشة، لأنه يُبدّل الراوتر.

الفاحص: `test/router_contract_test.dart`.

### R09 · وجهة واحدة لكل نتيجة 👁

> **لماذا**: نتيجةٌ واحدة بوجهتين تشحن بناءً إنتاجياً إلى شاشةٍ لم تُقصد له —
> غيابُ الجلسة يذهب إلى `LoginRoute` وحدها، لا إلى شاشة تجربة.

## د) الواجهة

### R10 · لا نصّ مكتوباً بالكود — أربع خطوات دائماً 👁

`ar.json` + `en.json` + `gen_code.dart` + `LocaleKeys.x.tr()`.

**ممنوع**: `Text('نص عربي')` · مفتاح بـ`ar.json` وحده · `locale.languageCode == 'ar'`
(استعمل `context.isAr`).

### R11 · `context.locale;` بأعلى كل `build()` يستعمل `.tr()` 👁

```dart
// ignore: unnecessary_statements — يسجّل العنصر لتغيّر اللغة
context.locale;
```

> **لماذا**: `.tr()` **لا تسجّل** الـelement تلقائياً. بدون السطر تتجمّد النصوص على
> اللغة التي بُنيت بها الشاشة أول مرة — والعطل لا ينهار ولا يُبلّغ.

### R12 · لا لون ولا حجم خطّ خامّين 👁

```
Figma hex → palettes/*.json ⇒ AppPalette (خام، مولَّد) → AppColors.light/dark (دلالي) → context.colors.X
```

**ممنوع**: `Color(0xFF...)` بالـUI · `Colors.blue` · `AppPalette.X` خارج
`app_colors.dart` · `TextStyle(fontSize: 16)` · `Theme.of(context).textTheme`.
**البديل**: `context.textTheme.bodyMedium?.copyWith(color: context.colors.X)`.

### R13 · كل `Text` بـ`Row` أفقي داخل `Expanded` + `ellipsis` 👁

بدونها: `RenderFlex overflow` وقت التشغيل عند أول نصّ طويل — وهو **بيانات المستخدم**
لا بيانات التجربة.

### R14 · لا `Image.network` مباشرةً 👁

بلا cache ولا placeholder ولا widget خطأ. استعمل `NetworkImageWidget` ·
`CachedImageWidget` · `AvatarWidget` — ودائماً `url ?? ''`.

### R15 · المحتوى ينتهي عند الشريط السفلي لا خلفه 🔒

القشرة (`MainShellScreen`) **بلا** `extendBody`: جسدُ كل تبويب ينتهي عند حافّة
`AppBottomBar` العليا، فلا تحتاج شاشةُ تبويبٍ حشوةً لترى آخر عنصرها. والشاشةُ خارج
القشرة (مدفوعةٌ فوقها) تنتهي قائمتُها بـ`context.bottomContentInset` — شريطُ إيماءات
النظام.

> **لماذا**: شريطٌ يجلس **فوق** الجسد يُخفي آخر عنصرٍ بكل قائمة، والعطلُ صامت —
> الشاشة تُبنى وتُمرَّر ولا يُرمى شيء. وحشوةٌ تُطلب من كل قائمة تُنسى في واحدة.

**والاستثناءُ الوحيد شريطٌ نافذ** (`ShellAppearance(translucent: true)`، مطفأٌ
افتراضاً): المحتوى يمرّ تحت الشريط ليُرى من خلاله، فالقشرةُ تُشغّل `extendBody`،
ويصل ارتفاعُ الشريط إلى الجسد بـ`context.bottomContentInset`. `ListView` بلا
`padding` يحشو نفسه به؛ **وكلُّ شاشة تبويبٍ تحدّد `padding` أو تثبّت زرّاً بأسفلها
تضيف `context.bottomContentInset` بيدها** — ثمنُ الخيار على من يُشعله.

الفاحص: `test/bottom_content_inset_test.dart` — يبني القشرةَ ويقيس أن الجسد ينتهي
عند الشريط، ونافذاً أنّ ارتفاعَ الشريط يصله حشوةً. ولا `extendBody` بالقشرة إلا
`look.translucent`.

### R34 · افحص `lib/ui/widgets/` ومستهلكيها قبل بناء أي ودجة جديدة 👁

قبل إنشاء ودجة، ابحث أولاً في `lib/ui/widgets/widgets.dart` — قد تكون موجودة
وناقصةً قدرةً صغيرة، لا معدومة كلياً. وقبل افتراض أنها «مشتركة عبر التطبيق فلا
تُعدَّل»، تحقّق فعلياً: `grep -rn "WidgetName("` عن مستهلكيها الحقيقيين — لا
تكتفِ بالظنّ.

> **والأثر حين تُتجاوز ودجةٌ موجودة**: نسخٌ يدويّة تنحرف قبل أن يلاحظ أحد —
> `maxLines` يختلف بين قسمٍ وآخر، وحسابُ الأحرف الأولى يُكتب أربع مرّات فيأخذ
> بعضُها اسمَ الأب لا الشخص. ولا مصرِّف ولا فاحص يرى ذلك: كلها سلاسل صحيحة.
> والقدرةُ الناقصة سطران داخل الودجة نفسها، لا ملفٌّ جديد يوازيها.

### R35 · مؤشّر التقدّم واحدٌ — `AppProgress` وحده 🔒

**ممنوع بأي ملف تحت `lib/`** (عدا `ui/widgets/indicators/app_progress.dart`):
`CircularProgressIndicator` · `LinearProgressIndicator` ·
`RefreshProgressIndicator` · `CupertinoActivityIndicator`.

> **لماذا**: كل موضعٍ يبني مؤشّره بيده يختار سُمكاً ولوناً وجذعاً بلا قرار تصميم،
> فيخرج التطبيق بمؤشّراتٍ متنافرة. **ولا `dart analyze` يراه ولا اختبار**: كلّها
> استدعاءات سليمة، والفرق بالبكسل لا بالسلوك — ما لا يكشفه إلا فاحصٌ آليّ (R30).

> **و`progressIndicatorTheme` لا يكفي**: يوحّد اللون الافتراضي وحده، ولا رأي له
> بالمقاس ولا السُّمك ولا التدرّج ولا حركة القيمة — و`color:` صريحٌ بأي موضع يُبطله.

**والتخصيص غير ممنوع بل مركزيّ**: النغمة (`AppProgressTone`) والمقاس
(`AppProgressSize`) افتراضان مُوحَّدان، وفوقهما وسائط تتجاوز كل قرار —
`color` · `trackColor` · `gradient` · `strokeWidth` · `dimension` · `height` ·
`radius` · `padding` · `centered` · `animate` · `adaptive`.

الفاحص: `scripts/check_structure.dart` → `F35`.
الاستعمال: [`21_WIDGETS_USAGE.md`](../ui/21_WIDGETS_USAGE.md) §26.

### R36 · حقل الإدخال واحدٌ — `CustomTextField` وحده 🔒

**ممنوع بأي ملف تحت `lib/`** (عدا `ui/widgets/inputs/`): `TextField(` · `TextFormField(`.
الفاحص: `F36` بـ`scripts/check_structure.dart`.

> (`onTapOutsideDismissTheKeyboard` = `true` افتراضاً)، والفاحص يمنع ولادة حقلٍ خارجه.

### R37 · كل رقمٍ يعتمد على الشاشة يمرّ بـ`context.screen` 🔒👁

```dart
final s = context.screen;
ResponsiveGap(24)                       // ❌ SizedBox(height: 24) · 24.heightBox
EdgeInsets.all(s.space(16))             // ❌ 16.allPadding
Icon(Icons.x, size: s.size(24))         // ❌ size: 24
EdgeInsets.symmetric(horizontal: s.gutter)
s.pick(compact: 1, expanded: 2)         // ❌ if (width > 600)
```

**وجسدُ كل شاشة داخل `ResponsiveContentBox`**، وما يمتدّ إلى الحافة — ترويسةٌ
ملوّنة، شريطٌ، صورةُ عرضٍ كامل — يبقى خارجه.

**الاستثناءان:**

| ✅ يبقى كما هو | لماذا |
|---|---|
| مقاسُ الخطّ من `context.textTheme` | السلّم يملكه، و`ResponsiveScope` يقيّد تكبير النظام فوقه. ضربُه بمعاملٍ ثانٍ يكسر تسهيلات الرؤية |
| `maxHeight: context.sh * 0.85` | **قيدٌ لا مسافة** — سقفُ ورقةٍ سفلية، قياسُ شاشةٍ حقيقيّ |

**لماذا**: فاصلٌ مثل `context.sh * 0.08` نسبةٌ من **ارتفاع الشاشة كاملاً** لا
تتقلّص حين يقتطع الكيبورد نصف الجسد — فيخرج أسفلُ الشاشة، وفيه زرُّها، خارج الحدّ.

**والأرقامُ مفحوصةٌ آلياً، والباقي بالعين:**

- **F37** — `context.sh *` مسافةً، و`setPreferredOrientations` خارج `OrientationPolicy`.
- **F38** — كلُّ مسافةٍ بعددٍ خامّ بـ`features/` و`ui/`: `SizedBox(height: 24)` · `SizedBox(width: 40)` ·
  `EdgeInsets.all(16)` · `16.allPadding` · `24.heightBox`. البديل `ResponsiveGap(24)` · `s.space(16)` ·
  `s.size(40)` · `s.gutter`. والصفرُ وما دون الواحد ليسا مسافة.

و`features/` و`ui/` بالقالب **بلا دَينٍ F38** — فأيُّ رقمٍ خامٍّ يُفشِل البناء من أوّل سطر.
⚠️ **وبمشروعٍ سجّل دَينَه بالأساس** (`41_UPGRADING.md`): المفتاحُ لكل ملف لا لكل سطر،
فملفٌّ عليه دَينٌ F38 لا يُفشِله رقمٌ مضاف حتى يُنظَّف كلُّه — فنظّف الملفَّ كاملاً حين تلمسه.

⚠️ **وجرّب على ثلاثة قبل التسليم**: هاتف ~٣٦٠ · لوحٌ عموديّ (٨٠٠) · لوحٌ أفقيّ (١٢٨٠).
فرعُ اللوح لا يُبنى على هاتفٍ أصلاً، فخطؤه لا يظهر إلا هناك — و`dart analyze` نظيفٌ عليه.

التفصيل والقوالب: [`22_RESPONSIVE.md`](../ui/22_RESPONSIVE.md).

## هـ) الحدود المعمارية

### R16 · اتجاه التبعية — لا استثناء 👁

```
foundation  → لا شيء
platform    → foundation
infra       → foundation + platform
modules     → foundation + infra
features    → foundation + infra + modules
ui          → foundation + infra + platform
di          → كل شيء (استثناء جذر التركيب)

core → features        ❌ أبداً (عدا di/)
core → presentation    ❌ أبداً (عدا di/)
features → features    ❌ أبداً
modules → features     ❌ أبداً
```

### R17 · استثناءان فقط لـ features → features 👁

`auth/shared/` (`AuthUser` · `CurrentUserRepository`) و
`auth/logout/.../logout_section.dart` (widget يملك cubit داخلياً).

> **الاختبار الذي يجعل الاستثناء مقبولاً**: المستهلك يستورد **الـwidget وحده**، ولا
> يعرف اسم أي cubit، ولا يوفّر `BlocProvider`، ولا يستورد من `domain/` أو `data/`.
> احتاج أياً منها ⇒ الحدّ مكسور، فانقل المشترك إلى `ui/widgets/`.

### R18 · محوّل المزامنة يسكن `<feature>/data/sync/` وحده 🔒

الفاحص: `test/sync/deletion_contract_test.dart` — ليبقى حذف الموديول **حذف مجلد**
لا بحثاً بالمستودع.

## و) الشبكة والتخزين

### R19 · ترتيب `dio.interceptors` سلوكٌ لا تفصيل 🔒

الكاش **قبل** حارس الاتصال.

> **لماذا**: بالترتيب المعكوس يُرفض الجهاز المنقطع **قبل** استشارة الكاش — فيعمى
> الكاش بالحالة الوحيدة التي وُجد لأجلها. قائمةٌ قرأها المستخدم قبل دقيقة جوابٌ
> أفضل من «لا إنترنت».

المصدر الوحيد: `injection_module.dart`. الفاحص: `test/request_cache_interceptor_test.dart`.

### R20 · `catch (_) {}` ممنوع — كل مسار احتياطي يسجّل 👁

> **لماذا**: قراءةٌ بلا `await` ⇒ تحويل يرمي ⇒ `catch` صامت — فالكاش يكتب مدخلاتٍ
> لا يقرؤها أبداً: **كاش بارد دائماً، بلا أي عَرَض يُبحث عنه**.

### R21 · `Accept-Language` بكل طلب — لا داخل `if (token != null)` 👁

> **لماذا**: داخلها، يصل كل رفض **قبل** الدخول — كلمة مرور خاطئة · حساب موقوف ·
> تجاوز محاولات · بريد مكرَّر — بلغة السيرفر الافتراضية.

### R22 · `StorageService.clear()` لا تُستدعى لمسح جزء 👁

> **لماذا**: تمحو **الثيم واللغة والخط ولقطة المستخدم** معاً، ولو استدعاها «امسح الكاش».
> من يملك بادئة يمسح مفاتيحه بـ`keys()` + `delete()`.

### R23 · التوكن بـ`SecureStorageService` وحده 👁

لا `StorageService` أبداً. مصدر الجلسة الوحيد: `core/infra/session/SessionRepository`.

Can(permission: PermKeys.ordersDelete, child: ...)   // ✅

## ح) التوثيق والحالة

### R26 · لا ملف توثيق خارج جدول المزامنة 👁

كل ملف بـ`readme/` **يجب** أن يكون بجدول «Mandatory Documentation Sync» بـ
[`../CLAUDE.md`](../../CLAUDE.md) وبفهرس [`README.md`](../README.md) معاً.

> **لماذا**: ملفٌ خارج الجدول لا يُذكّر به أحد حين يتغيّر الكود، فيصف موديولاً
> مبنيّاً بأنه «لم يُبنَ» أو مطفأً بلا أن يقول. **ولا شيء يفشل** حين تتقادم الوثيقة: التحليل نظيف،
> والاختبارات تمرّ، والوثيقة وحدها تكذب.

### R27 · `✅` تعني «له مستهلك هنا» لا «الملف وصل» 👁

> **لماذا**: `✅` على ملفٍّ لا يستورده شيء يدعو للبناء على سلسلةٍ مقطوعة. الفرق بين *سطح قالبٍ* و*سلسلةٍ عاملة* — ولا يميّزه المصرِّف ولا التحليل ولا
> الاختبارات، **كلها خضراء بالحالتين**.

### R28 · تحقّق أن السلسلة موصولة قبل أن تبني عليها 👁

قبل استعمال أي صنف مبنيّ وموثَّق، اسأل: **مَن يُسجّله بالـDI؟ مَن يركّبه بالشجرة؟
مَن يستورده؟** الجواب «لا أحد» ⇒ أنت أمام سطح قالبٍ لا سلسلةٍ عاملة.

الجرد الكامل: [`10_ARCHITECTURE.md`](../architecture/10_ARCHITECTURE.md) §«المبنيّ بلا مستهلك».

### R29 · كل موديول يُولد بأركانه معاً 👁

علَم بـ`AppFeatures` · سطر بـ`ModulesBootstrap` · صفّ بجدول [`30_MODULES.md`](../modules/30_MODULES.md) —
`scaffold_module.dart` يكتبها معاً.
واحدٌ ناقص ⇒ كود يُشحن ولا يُشعَل ولا يُطفأ.

> **وموديولٌ لا يتّسع له الإقلاع** (حوارٌ يحتاج `BuildContext`) ينقسم نصفين ولا
> يُعفى: `initialize(di)` بـ`ModulesBootstrap` يسجّل حالته، وحارسٌ بالقشرة يعرضها —
> مثاله `in_app_updates/` و`AppUpdateGate`. راجع [`10_ARCHITECTURE.md`](../architecture/10_ARCHITECTURE.md) §الموديولات.

### R30 · قاعدة مكتوبة بلا فاحص اقتراحٌ لا قاعدة 👁

أي قاعدة يجب أن يلتزم بها كل مطوّر ⇒ لها فاحص آلي أو اختبار، لا سطر بالتوثيق وحده.
الرمز 🔒 أعلاه يقول أيّها بلغ هذا الحدّ.

### R38 · الوثيقة تصف الحاضر — التاريخ بـgit و`_template/` 👁

ما يُنسخ إلى المشروع (`readme/` · `lib/**/*.md` · `CLAUDE.md` · تعليقات الكود)
يقول **ما هو موجود ولماذا**، لا **متى تغيّر ولمن حدث**. لا تاريخ، ولا اسمَ مشروعٍ
ظهر فيه العطل، ولا «كان كذلك حتى…». السببُ يبقى بسطرٍ واحد لأنه ما يُقنع بالقاعدة؛
القصةُ تذهب إلى رسالة الـcommit أو `_template/`.

الفاحص: `dart run scripts/audit_template.dart` §٥ (استشاريّ، `--verbose` للأسطر).

### R39 · كل رابطٍ بوثيقة يصل ملفاً موجوداً 🔒

نقلُ ملفٍّ أو حذفُه يكسر كل رابطٍ إليه، ولا شيء آخر يفشل. ورابطٌ إلى `_template/`
من خارجه رابطُ GitHub كامل (المجلد لا يصل المشاريع).

الفاحص: `dart run scripts/check_docs.dart` — حاجبٌ بالـCI.

### R40 · ابحث في كتالوج القدرات قبل أن تكتب أداة 🔒

تنسيقُ تاريخ أو رقم، أو غلافُ حزمة، أو ودجةُ حالة — ابحث أولاً بـ
[`06_CAPABILITIES.md`](06_CAPABILITIES.md). الناقص يُوسَّع بمكانه، لا نسخةً بجانبه.

> **لماذا**: خطّة نقلٍ تصف المشروع القديم لا القالب، فيُكتب عند التنفيذ ما هو
> موجود — دوالّ تاريخٍ وأرقامٍ متفرّقة بجانب `AppDateText` الذي لا يستعمله أحد.
> والنسخةُ الثانية تفقد ما يحمله الغلاف: السجلّ والترجمة والعلَم والاختبار.

الفاحص: `check_structure.dart` §`C01…C17` — النداءُ الخامّ للحزمة خارج غلافه يُفشل البناء.

### R41 · كل حركةٍ تأخذ مدّتها من `AppMotion.of(context)` 👁

المدّة من `AppMotion.of(context)` والمنحنى من `AppMotion` — فلا رقمَ بالشاشة، ولا
حركةَ تتجاهل «تقليل الحركة» (`MediaQuery.disableAnimations`): من فعّله لدوارٍ أو
لتشتّت يجد التطبيق ثابتاً كلّه، بلا علَمٍ لكل شاشة. وما لا مدّة له (هزّة · عدّاد)
يتخطّى نفسه حين `isReduced`. الحركاتُ الجاهزة بـ[`06_CAPABILITIES.md`](06_CAPABILITIES.md) §الحركة.

الاختبار: `test/motion_test.dart`.

### R42 · كل ودجةٍ عامّة لها مكانٌ بالجولة 🔒

ما دام `lib/modules/showcase/` موجوداً، كلُّ صنفٍ عامّ بملفٍّ يصدّره `widgets.dart`، **وكلُّ
ودجةٍ عامّة بـ`lib/ui/` و`lib/modules/`**، تظهر بالجولة: بمثالٍ حيّ، أو — لودجة موديولٍ
تحتاج خادماً — باسمها نداءً بجانب محاكاتها بصفحة موديولها، أو بسطرٍ مسبَّبٍ بـ`_exempt`.

> **لماذا**: الجولة مرآةُ القالب. ودجةٌ تُضاف للمكتبة بلا مثال تجعل المرآة تعرض أقلَّ
> مما يملكه القالب، ولا يلاحظ أحد — فيكتبها المطوّر ثانيةً لأنه لم يرها.

الاختبار: `test/modules/showcase_test.dart` — «every public class of the widget library…» و
«every public widget in lib/ui/ and lib/modules/…».
والمشروعُ الذي يحذف الجولة يحذف اختبارها معها ([`SETUP.md`](../../lib/modules/showcase/SETUP.md)).

### R43 · حِزَم الأجهزة منفصلة — التطبيق يعرف العقد وحده 🔒

ما يجرّ كوداً أصلياً ثقيلاً (صوت · كاميرا حيّة · تعرّف) kit تحت `packages/`.
`lib/` يستورد `kit_contracts` وحده، و`lib/core/di/kits.g.dart` المولَّد هو الملف
الوحيد الذي يستورد kit. والـkit لا تستورد التطبيق ولا kit أخرى، وحزمُ منصّتها لا
تُستورد خارجها.

> **لماذا**: العلَمُ يُطفئ التسجيل لا الحزمة — حزمةٌ ثقيلة بـ`pubspec.yaml` تُشحن في كل
> مشروع وتُسأل عنها مراجعةُ iOS. وkit يستوردها ملفٌّ بشاشة تكسر البناء بعشرة أماكن
> لحظةَ تُزال، بدل سطرٍ واحد يكتبه السكربت.

الفاحص: `check_structure.dart` — `C18` (الاستيراد) · `C19` (حزم المنصّة). التفصيل:
[`24_DEVICE_KITS.md`](../modules/24_DEVICE_KITS.md).

### R44 · النواة تُخبر ولا تعرف من يسمع 🔒

`core/` و`ui/` لا يستوردان `modules/token_inspector/`. النواة تُخبر عن الجلسة عبر
`AuthSessionObserver` (منفذٌ بـ`foundation/`)، والموديول يعلّق مستمعه على
`AuthSessionRelay`، ويسجّل طبقته المرئية بـ`AppOverlays` — فلا سطرَ بـ`app.dart`
يعرفه.

> **لماذا**: أداةُ مطوّرٍ تستوردها النواة مباشرةً تبقى بالكود حين تُطفأ، وتُشحن
> حين تُنسى، ويصير حذفُها بحثاً بستّة ملفات. وبالمنفذ، إطفاؤها علَمٌ، وحذفُها مجلّد.

الفاحص: `check_structure.dart` — `C20`. التفصيل:
[`33_MODULE_TOKEN_INSPECTOR.md`](../modules/33_MODULE_TOKEN_INSPECTOR.md).

## 🪤 فخاخُ المكتبات — خمسةٌ لا يمسكها تحليلٌ ولا مصرِّف

**ليست قواعدَ هذا المستودع، بل سلوكُ مكتباتٍ يخالف ما يبدو من اسمها.** وكلُّها
كلّفت وقتَ تصحيحٍ حقيقياً، وكلُّها موثَّقةٌ **بموضعها** — وهذا الجدول فهرسُها،
ليُقرأ الفخُّ **قبل** أن يقع لا بعده.

| # | الفخّ | الموضع |
|---|---|---|
| 1 | **`GetIt.getAll<T>()` يرمي عند الفراغ** — خلافاً للداخليّ الذي يُعيد قائمةً فارغة. والفرقُ لا يظهر ما دام ثمّة تسجيلٌ واحد، فيمرّ سنينَ ثم يرمي يومَ يُحذف آخرُ منفّذ. ⛔ **و`isRegistered<T>()` ليست البديل**: تقرأ التسجيلاتِ غيرَ المسمّاة وحدها | [`core/foundation/di/get_it_all_extension.dart`](../../lib/core/foundation/di/get_it_all_extension.dart) |
| 2 | **`@LazySingleton(as: Interface)` يسجّل تحت الواجهة وحدها** — فمن يحقن الصنفَ نفسَه (لأنه يحتاج طرائقَ ليست بالعقد) ينهار **وقت التشغيل**. و`injectable` يولّد `gh<X>()` راضياً، و`dart analyze` نظيف. والنمطُ الصحيح **تسجيلان بنسخةٍ واحدة** | [`core/foundation/contracts/account_scoped_store.dart`](../../lib/core/foundation/contracts/account_scoped_store.dart) |
| 3 | **`handler.reject(err)` وسيطُها الثاني افتراضُه `false`** — فلا يمرّ الخطأ على `onError` لأيِّ معترضٍ بعده. والنتيجةُ **حجبٌ بصمتٍ تامّ**: لا سطرَ بالطرفية ولا طلبَ بـDevTools | [`core/infra/network/interceptors/internet_checker_interceptor.dart`](../../lib/core/infra/network/interceptors/internet_checker_interceptor.dart) |
| 4 | **`InternetConnectionChecker` الافتراضي يضرب ثلاثة APIs تجريبية عامّة** — فشبكةٌ تحجبها تجعل التطبيق **أوف‑لاين للأبد** والخادمُ متاح | [`core/platform/connectivity/server_reachability.dart`](../../lib/core/platform/connectivity/server_reachability.dart) |
| 5 | **`workmanager 0.9.2` يفشل عند التصريف لا عند الحلّ** إن صعد `platform_interface` إلى `0.9.4` على Flutter 3.35 — فتُثبَّت الثلاثةُ معاً | [`pubspec.yaml`](../../pubspec.yaml) §`dependency_overrides` |

> **والقاسمُ بينها** أنها كلَّها **تُصرَّف نظيفةً**: لا `dart analyze` يراها ولا
> اختبارُ وحدةٍ يشكو، وأثرُها يظهر وقتَ التشغيل أو بسلوكٍ صامت. ولذلك مكانُها
> تعليقٌ عند السطر لا سطرٌ بوثيقة — والفهرسُ هنا بابٌ إليها.

⚠️ **وأيُّ فخٍّ جديد يُضاف بنفس الشكل**: تعليقٌ عند موضعه يقول ما وقع ولماذا، وصفٌّ
هنا. وفخٌّ يُكتشف ولا يُسجَّل يُكتشف ثانيةً بمشروعٍ آخر.

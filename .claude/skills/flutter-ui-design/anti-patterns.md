# Anti-Patterns — "Generic UI"

"Generic UI" (تعريف المستخدم، ثابتٌ منذ فتح هذا الـskill): واجهةٌ **صحيحة
تقنياً** — لا تخالف قاعدة واحدة بـ`CLAUDE.md`، `dart analyze` نظيف،
`check_structure.dart` بلا مخالفة — لكن بلا composition ولا شخصية بصرية.
`Container + Padding + BorderRadius + Color + Text + Icon` بلا قرارٍ
وراءها.

يُقرأ هذا الملف أثناء مرحلة Critique بـ[`SKILL.md`](SKILL.md)، أو عند مراجعة
شاشةٍ موجودة.

## المصداق الحيّ بالمستودع — `login_screen.dart`

وُثِّق بالتحليل الأصلي ([`_template/roadmap.md`](https://github.com/mohammeddaeh/project-template-app/blob/master/_template/roadmap.md) #16):
`Column` عمودي واحد (عنوان → subtitle → حقلان → زرّ → صفّ) — بلا `Card`،
بلا عمق، بلا صورة/هويّة بصرية، hierarchy من حجم الخط فقط. **الميكانيكا
سليمة** (action hierarchy صحيح، validation صحيح) — المفقود composition لا
صحّة. هذا المثال المرجعي لكل بند أدناه، لا افتراضٌ نظري.

## علامات حمراء — لو ظهرت، ارجع لمرحلة Plan

| العلامة | لماذا خطأ | البديل |
|---|---|---|
| `Column` رأسيّ واحد يحوي كل شيء، بلا `Card`/سطح فرعي | صفر hierarchy مكانية — كل العناصر بنفس "الطبقة" البصرية | راجع `composition-guide.md` §Card-vs-Surface |
| أوّل عنصرٍ مرسوم نصّ عنوانٍ عادي | صفر focal point — العين لا تعرف أين تبدأ | راجع §Focal-Point بنفس الملف |
| `SizedBox(height: N)` بأرقامٍ خام متفرّقة (٨، ٤٠، ٢٠...) | إيقاع مسافة عشوائي لا مقصود — R37 موجودة ولا تُستخدم | `context.screen.space(N)`/`ResponsiveGap` |
| `elevation: 0` بكل مكان بلا استثناء واحد | لا فرق بصري بين "خلفية" و"عنصر مهم" — التطبيق مسطّحٌ بالكامل | `AppElevation.md/lg` للعناصر التي تستحقّ الإبراز فعلاً |
| زوايا `12` بكل مكان بلا تنويع | لا تمييز بصري بين مستويات المحتوى | راجع جدول Radius/Elevation بـ`composition-guide.md` |
| ألوان مشبَّعة/متدرّجة لا تطابق `AppPalette` | يخالف R12 مباشرةً، وأيضاً يكسر نبرة القطاع (راجع §السياق بـ`SKILL.md`) | `context.colors.X` حصراً |
| ودجة/شاشة جديدة تُبنى قبل فحص `ui/widgets/` | تكرارٌ محتمل — راجع R34، وقعت ٣ مرّات موثَّقة بـ`03_RULES.md` | `grep -rn "WidgetName("` أولاً |
| نصّ placeholder ("Lorem"، "شاشة تجريبية") بخطة نهائية | لا تُحكَم جودة composition على محتوًى وهميّ — القرار يختلف بمحتوى حقيقي | استخدم بيانات حقيقية من الطلب نفسه |

## ما هو **ليس** Generic UI — لا تُصلح ما لا يحتاج إصلاحاً

- **شاشة placeholder مُعلَنة بقصد** (`home_screen.dart` الحالية) — موثَّقة
  بتعليق الكود نفسه أنها تُستبدل لاحقاً. لا تُحكَم بنفس معيار شاشةٍ نهائية.
- **سطحٌ مسطّح مقصود** (حالة فارغة، شاشة بيانات كثيفة تحتاج وضوحاً لا زخرفة)
  — `AppElevation.none` قرارٌ صحيح هنا، لا نقصاً.
- **التزامٌ صارم بـR12/R34-R37** حتى لو بدا "مقيِّداً بصرياً" — القيد الصلب
  بـ`SKILL.md` لا يُتجاوز أبداً بحجّة تحسين composition.

# Showcase Module — المرآة: جولة المطوّر

جولةٌ بتبويب الرئيسية تعرض ما بناه القالب **بالودجات الحقيقية**، مرتّبةً بستّة فصول:

| الفصل | الصفحات |
|---|---|
| الأساسات | الألوان · الخطوط · المسافات والزوايا · مقاس الشاشة · التاريخ والأرقام · أدوات الأساس |
| الودجات | الأزرار · الإدخال · العرض · السحب والترتيب · الصور والمرفقات · التنقّل · الحوارات والأوراق · التنبيهات والمؤشّرات · الحالات والتحميل |
| الحركة | الحركات الجاهزة · حراسة الرجوع |
| البيانات | قائمةٌ بصفحات · الكيوبتات وحالاتها · إضافة وتعديل وحذف · الأخطاء · محاكي الطلبات |
| الموديولات | الدخول · الاستيراد والتصدير · الصلاحيات · طابور المزامنة — **محاكاةٌ محلّية** |
| المنصّة | الاهتزاز · المشاركة والنسخ · الاتصال · أعلام التطبيق · التخزين والإعدادات · المظهر واللغة |

كل بطاقةٍ تتمدّد إلى صفحتها (`AppOpenContainer`). **وكل ودجةٍ لها خيارات «ملعب»**
(`DemoPlayground`): خياراتُها أدواتُ تحكّم تحت المثال، وأيُّ تغييرٍ يبدّل الودجةَ والنداءَ
المكتوبَ فوقها معاً — فيُنسخ النداء كما اختير.
**لا تحتاج خادماً**: صفحاتُ البيانات والموديولات تحاكي الخادم محلّياً، وكلٌّ منها يذكر
نقطةَ الدخول الحقيقية.

## مرآةٌ لا عرضٌ ثابت (R42)

كلُّ صنفٍ عامّ بملفٍّ يصدّره `lib/ui/widgets/widgets.dart` له مثالٌ بصفحةٍ هنا —
`test/modules/showcase_test.dart` يُفشل الناقص ويسمّيه. فودجةٌ جديدة بالمكتبة تأتي
بمثالها بنفس التغيير، أو بسطرٍ مسبَّبٍ بـ`_exempt` في الاختبار.

## الحالة الافتراضية — مُشعَل

```dart
// lib/core/platform/features/app_features.dart
static const showcase = true;
```

مشروعٌ جديد يفتح على الجولة، فيرى المطوّر ما هو مبنيٌّ قبل أن يكتبه ثانيةً.
والجولة تُرسم بدل جسد `HomeScreen` الافتراضيّ — لا مسار لها ولا تسجيل DI.

## الإطفاء — حين تصل رئيسية المشروع

1. `static const showcase = false;`
2. احذف `lib/modules/showcase/` و`test/modules/showcase_test.dart`.
3. بـ`lib/features/home/presentation/pages/home_screen.dart`: احذف سطرَي
   الاستيراد (`app_features` · `showcase_view`) والشرطَ بـ`body:` — أو استبدل الجسد
   كاملاً برئيسية المشروع.
4. بـ`lib/modules/modules_bootstrap.dart`: احذف الاستيراد والكتلة
   `if (AppFeatures.showcase)`.
5. احذف العلَم من `app_features.dart`، ومفاتيح `showcase*` من
   `assets/translations/*.json`، ثم `dart run scripts/gen_code.dart`.

`dart run scripts/prune_project.dart` يعرض الموديول حين يكون علَمه مطفأً.

## إضافة صفحة

ملفٌّ بـ`presentation/pages/<الفصل>/` فيه ودجةٌ تصفّ أمثلتها: `DemoPlayground` لودجةٍ لها خيارات
(`apiDefault` لكل خيارٍ = افتراضُ الودجة الحقيقي)، و`DemoBlock(code: …)` لما سواها،
ثم سطرٌ بـ`ShowcaseCatalog.pages` (`presentation/showcase_catalog.dart`). الصفحة التي
تمرّر نفسها (قائمةٌ بصفحات) تأخذ `ownsScroll: true`. واختبار الرسم يمرّ على كل صفحةٍ
بالكتالوج **بلا DI** — خدمةٌ من `getIt` تُفحص بـ`isRegistered` قبل استعمالها.
